# MacroHard Todo

一个本地优先、简洁轻快的桌面任务管理应用，为长期使用 Microsoft To Do 的用户准备：界面与交互尽量贴近原版，但**数据完全在你自己手里**，不依赖任何服务器，微软停服也不影响使用。

> 本项目是独立实现，与微软没有任何关联，也不包含微软的图标、图片或商标。图标使用开源图标库 Lucide（ISC 许可），线性风格接近原版。

## 已实现功能

- **列表**：新建、重命名、颜色、拖拽排序、删除
- **任务**：标题、备注、截止日期/时间、提醒、星标（重要）、标签、附件
- **步骤**：任务内子步骤、勾选进度
- **智能视图**：我的一天、重要、计划内、全部、已完成
- **默认任务清单**：固定的「任务」清单；不属于任何清单的新任务会自动进入这里
- **我的一天**：手动加入 + 自动建议（今天到期、已逾期）
- **重复任务**：每天/每周/每月/每年、间隔、指定星期、结束日期
- **提醒**：系统通知（应用运行时检查）
- **搜索**：标题、备注、标签、步骤
- **外观**：浅色 / 深色 / 跟随系统，配色与尺寸对齐 MS To Do
- **背景主题**：每个列表和「我的一天」都能选**整页背景**（8 套内置矢量插画 + 任意本地图片）与 emoji 图标；自定义图片随 WebDAV 同步
- **我的一天**：整页背景 + 居中欢迎卡片 + 右侧可开合的「建议」面板（已逾期/今天/稍后/最近添加）
- **底部添加栏**：除「已完成」外每个页面都有固定在窗口底部的添加任务栏；在重要页添加自动星标、计划内页添加自动今天到期
- **已完成页面**：侧栏独立的已完成视图，可恢复任务
- **托盘**：关闭窗口最小化到托盘，托盘菜单可打开/快速添加/退出
- **全局快速添加**：`Ctrl + Alt + T`
- **数据**：自动保存、每日备份、JSON 导入导出、CSV 导入导出
- **WebDAV 同步**：坚果云 / Nextcloud / 群晖，按任务最后修改时间合并，可选 AES-256-GCM 加密
- **微软 To Do 迁移**：通过 Microsoft Graph 设备码登录，自动导入列表、任务、步骤、日期、提醒、重要、重复、备注

## 开发与构建

### 环境要求

- Node.js 20+
- Rust stable（MSVC 工具链）
- Visual Studio 2022 Build Tools（C++ 工作负载 + Windows SDK）
- WebView2（Windows 11 自带）

本项目已配置为：
- Rust：`C:\software\cargo` / `C:\software\rustup`
- VS Build Tools：`C:\software\VS2022BuildTools`

### 运行

```powershell
npm install
npm run tauri dev
```

### 测试

```powershell
npm test
```

### 打包

```powershell
npm run tauri build
```

产物在 `src-tauri/target/release/bundle/nsis/`，安装包为 currentUser 模式，无需管理员权限。

## 数据位置

`%APPDATA%\com.macrohardtodo.app\`

- `todo-data.json`：主数据文件
- `backups\todo-YYYY-MM-DD.json`：最近 21 天的每日备份
- `attachments\`：附件文件

## WebDAV 同步

以坚果云为例：

1. 在坚果云里新建一个文件夹，例如 `MyTasks`
2. 登录坚果云网页版 → 账户信息 → 安全选项 → 添加**应用密码**
3. 打开应用「设置 → 同步」：
   - 地址：`https://dav.jianguoyun.com/dav/MyTasks`
   - 用户名：登录邮箱
   - 密码：上一步的应用密码
4. 点「测试连接」，成功后「保存并同步」

同步会在网盘里创建 `MyTasks/MacroHardTodo/data.json`。换新设备时填同样的配置并同步即可。

- 合并规则：按每条数据的 `updatedAt` 取较新者，时间相同按设备 ID 决胜；删除使用墓碑标记，不会复活
- 冲突：上传使用 `If-Match`，遇到 412 会自动重新下载合并再上传
- 加密：设置口令后网盘里只存密文；**口令丢失无法恢复**
- 附件：本地有而远端没有时会自动上传；收到别处的附件记录时按需下载

## 从微软 To Do 迁移

1. 打开 https://portal.azure.com → Microsoft Entra ID → 应用注册 → 新注册
2. 名称随意；受支持的帐户类型选「仅个人 Microsoft 帐户」或「任何组织目录 + 个人帐户」
3. 重定向 URI 留空，点「注册」
4. 复制「应用程序(客户端) ID」
5. 「身份验证」→ 允许公共客户端流 → 是 → 保存
6. 「API 权限」→ 添加权限 → Microsoft Graph → 委托的权限 → `Tasks.Read` → 添加
7. 回到应用「设置 → 从微软 To Do 迁移」，粘贴客户端 ID，登录并导入

迁移可重复运行，已导入的任务按 `sourceId` 去重，不会重复创建。

**无法迁移**：My Day 的历史安排、标记邮件（Graph 接口不提供）。

## 已知限制

- 提醒依赖应用运行：关闭到托盘可继续提醒；完全退出后不会提醒。可在设置中开启开机自启
- 多个设备同时修改同一条任务时，以最后修改时间为准（不做字段级合并）
- 中国大陆访问微软登录域名可能较慢，迁移向导请耐心等待
- WebDAV 服务器若不支持 ETag（部分服务商），会自动降级为「下载 → 合并 → 上传」
