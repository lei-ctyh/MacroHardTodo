# 对齐微软 To Do 的视图分组规则

## Goal

按参考截图的分组交互补全任务列表的分组能力：我的一天 / 重要补齐底部「已完成 N」折叠区，计划内按日期范围分组（已完成任务留在组内划线显示），全部和已完成按列表分组，并统一分组标题胶囊。

## Background

当前实现里只有**列表视图**（默认「任务」+ 自定义列表）有底部「已完成 N」折叠区；智能视图直接过滤或平铺。参考截图（2026-11-26）显示：

- 我的一天：任务平铺 + 底部「已完成 N」胶囊
- 全部：按列表分组，组标题 = 列表名 + 数量，可折叠
- 已完成：按列表分组，组标题 = 列表名（无数量），可折叠，组内完成时间倒序
- 计划内：按日期分组，组标题 = 日期范围 + 数量（如「今天 2」「11月28日,周六到12月2日,周三 1」）；**已完成任务留在组内划线显示，没有底部已完成区**
- 任务行 meta 显示「☀ 我的一天」文字（我们现在只有太阳图标）

## 分组规则

| 视图 | 主体内容 | 分组方式 | 组标题数量 | 组内排序 | 底部「已完成 N」 |
| --- | --- | --- | --- | --- | --- |
| 任务 / 自定义列表 | 未完成任务 | 不分组，平铺 | — | 视图排序（默认我的顺序） | ✅ 该列表全部已完成，完成时间倒序 |
| 我的一天 | 今天加入的未完成任务 | 不分组，平铺（行内显示来源列表） | — | 视图排序 | ✅ `myDay = 今天` 且已完成 |
| 重要 | 重要未完成任务 | 不分组，平铺（行内显示来源列表） | — | 视图排序 | ✅ 重要且已完成 |
| 计划内 | 带截止日期/提醒的任务，**含已完成**（划线） | 日期桶：已逾期 → 今天 → 明天 → 接下来 5 天 → 以后 | 显示（含已完成） | 桶内按视图排序 | ❌ 不显示 |
| 全部 | 所有未完成任务 | 按列表分组，顺序跟随侧栏 | 显示 | 组内按视图排序 | ❌ 不显示 |
| 已完成 | 所有已完成任务 | 按列表分组，顺序跟随侧栏 | 不显示（按截图） | 完成时间倒序 | ❌ 不显示 |

统一胶囊：高 36px、圆角 4px、14px 常规字重、16px 箭头、主题感知填充色；结构为 `箭头 + 名称（+ 数量）`；点击切换折叠。

### 计划内日期桶

- 已逾期：生效日期 `< 今天`（按日期比较，不按时间；今天已过点仍留在「今天」）
- 今天：`= 今天`
- 明天：`= 明天`
- 接下来 5 天：`今天 + 2` 到 `今天 + 6`，标题显示日期范围，格式如「11月28日,周六到12月2日,周三」
- 以后：`> 今天 + 6`
- 生效日期 = `dueDate ?? reminderAt 的日期`
- 已完成任务与未完成任务一起分桶、一起计数，完成的行显示为划线
- 空桶不渲染

### 按列表分组（全部 / 已完成）

- 组顺序与侧栏一致：未分组列表在前，然后按列表分组顺序，组内按列表顺序。
- 没有任务的列表不渲染。
- 全部：对象是未完成任务；已完成：对象是已完成任务，组内 `completedAt` 倒序。
- 组内任务行不再重复显示来源列表名（组标题已经表达）。
- 只渲染现存列表；找不到所属列表的任务不显示，不建「其他」组。

### 删除列表

- 删除列表时，把该列表的**全部任务（含已完成）移动到默认「任务」列表末尾**，再软删除列表；任务本身不删除。
- 因此正常流程下不会出现「任务不属于任何现存列表」的情况；历史数据若出现，按上一条不显示。

### 任务行 meta

- 「我的一天」标记改为「☀ 我的一天」（图标 + 文字），与截图一致；其余 meta 顺序保持现状。

### 搜索

- 先按搜索词过滤任务，再构建分组；空分组不渲染，数量随之变化。
- 底部「已完成 N」同样按搜索词过滤，无匹配时隐藏。

## Requirements

- R1: 我的一天、重要补齐底部「已完成 N」折叠区，复用现有胶囊和交互。
- R2: 计划内按「已逾期 / 今天 / 明天 / 接下来 5 天（日期范围标题）/ 以后」分桶，含已完成任务，空桶隐藏。
- R3: 全部按列表分组，组标题为「列表名 + 数量」，可折叠，组顺序跟随侧栏。
- R4: 已完成按列表分组，组标题为列表名，可折叠，组内完成时间倒序。
- R5: 所有分组标题使用同一套胶囊样式，尺寸/字重/间隙与当前「已完成 N」一致。
- R6: 列表视图行为保持不变（平铺 + 已完成区 + 拖拽排序）。
- R7: 搜索时分组按过滤结果重建，空组和空已完成区隐藏。
- R8: 分组折叠状态按视图保存到本地 settings，重启后保留。
- R9: 全部 / 已完成的分组内任务不显示来源列表名。
- R10: 任务行「我的一天」标记显示图标 + 文字。
- R11: 删除列表时把任务移到默认「任务」列表末尾，不随列表删除。

## Acceptance Criteria

- [ ] 我的一天：未完成平铺，底部「已完成 N」，展开/折叠、数量正确。
- [ ] 重要：同上，只统计重要且已完成的任务。
- [ ] 计划内：已逾期/今天/明天/接下来 5 天/以后 分桶正确；已完成任务留在组内且划线；空桶不显示；日期范围标题格式正确。
- [ ] 全部：按列表分组，组名/数量正确，组顺序与侧栏一致，折叠正常。
- [ ] 已完成：按列表分组，组顺序与侧栏一致，组内完成时间倒序，折叠正常，组标题无数量。
- [ ] 列表视图：平铺、拖拽排序、已完成区与现状完全一致。
- [ ] 搜索：各视图分组按命中结果重建，无匹配时显示空状态。
- [ ] 主题背景（含浅色主题）下胶囊文字/填充/箭头对比度正常。
- [ ] 任务行显示「☀ 我的一天」文字。
- [ ] 删除列表：任务（含已完成）移动到默认「任务」列表末尾，列表消失、任务保留。
- [ ] `npm test` 与 `npm run build` 通过。

## 已确认的决定

1. 计划内：不要底部「已完成 N」，已完成任务留在日期组内划线显示。
2. 全部：不要底部「已完成 N」。
3. 折叠状态跨重启保留（只存本地，不参与同步）。
4. 「逾期」按日期判定。
5. 计划内组标题显示数量（含已完成）。
6. 任务行「我的一天」标记带文字。
7. 已完成视图按列表分组，组标题不显示数量。
8. 删除列表时任务移动到默认「任务」列表，不随列表删除。
9. 找不到所属列表的任务在全部/已完成里不显示。

## Out of Scope

- 不引入微软的「已分配给我 / 已标记的电子邮件」视图。
- 不新增按「重要 / 截止日期 / 我的一天」等字段的分组切换（只做上表的固定规则）。
- 不改侧栏的列表分组（分组管理）功能。
